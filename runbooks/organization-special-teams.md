# Organization Special-Teams Personnel Runbook

This workflow records organization-scoped specialist assignments against the controlled six-unit NFL special-teams bible. Each assignment requires a role, responsibilities, source reference, mastery evidence, and human review owner. It does not infer live roster status or make health/clearance decisions.

Coaching staff submit `POST /v1/special-teams/organization-package`. A program owner validates the package with a DEC-* or APPROVAL-* reference. Validation evidence does not activate production or replace rule-authority review.
