# Organization Performance Review Runbook

This workflow composes organization-scoped, non-diagnostic performance observations and readiness summaries. Health-related signals remain qualified-staff review items; the package never diagnoses, clears, treats, or changes return-to-play status.

Performance staff submit `POST /v1/performance/organization-package` with an authorized source manifest and records. A program owner validates the package with a DEC-* or APPROVAL-* reference. Provider adapters, live credentials, and medical or performance-staff operations remain separate deployment concerns.
