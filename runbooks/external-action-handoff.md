# External Action Handoff

Run `PYTHONPATH=src python scripts/external_action_handoff.py` to generate a value-free packet grouping every remaining Master Plan requirement by responsible authority and required inputs.

The packet is planning evidence only. It does not create organization data, record approvals, enable production, advance the stage, deploy providers, or change external state. Rebuild it after each approved external action so the remaining work stays synchronized with the traceability ledger.
