# Permission denial

1. Preserve the denial event, request ID, actor, role, organization, resource, and action.
2. Confirm the principal is authenticated and the organization scope matches.
3. Check whether the action is high-impact or the artifact is locked.
4. Do not widen access to make a workflow pass; request explicit approval or correct the assigned role.
5. Re-test both the allowed and denied paths and retain the audit evidence.
